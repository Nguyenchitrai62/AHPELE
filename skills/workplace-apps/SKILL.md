# Workplace applications over MCP

## Discover
- List the servers and their tools once; save the tool list to `/tmp/ahpele/mcp_tools.md` with one line per tool
  (name: purpose, required arguments) so you do not need to list them again.
- Prefer read/search/list tools to explore; note IDs (project, work package type, status, user) you will need.

## Read the record
- Search mail and documents by project identifiers, names and dates; read full threads, attachments and their dates.
- The record "as of" a date excludes anything dated later.
- Keep a dated timeline and a list of sources (application, item id, title, date) for citations.

## Create or update
- Before creating, check whether a suitable item already exists, and the required fields (project, type, subject,
  description, assignee, status, dates, priority, custom fields).
- Put the substance in the item: the determination, each open item with its owner and due date, and references to the
  documents it rests on. Keep it consistent with any memo or file you deliver.
- Use the exact project, list or folder the instruction names.

## Confirm
- After every create/update, read the item back and verify the fields are stored as intended. If a call fails, read the
  error, fix the arguments and retry; do not assume success.
- Mention every created or updated item (application, id, title) in your final message.
